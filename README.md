# Dogs vs Cats MLOps Project

This project implements a reproducible machine learning workflow for
Dogs vs Cats image classification.

## Project Goals

- Version code with Git
- Version datasets and models with DVC
- Track reproducible experiments
- Use Git branches and pull requests for collaboration
- Run automated CI checks
- Produce a reproducible production release

The project uses Git, DVC, pinned dependencies, configuration files,
and fixed random seeds to make experiments reproducible.
